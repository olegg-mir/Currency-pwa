# Currenzy: техническое описание

## Назначение и границы продукта

Currenzy — mobile-first PWA для справочного пересчёта фиатных и криптовалют. Приложение не исполняет сделки, не учитывает комиссии, банковские спреды и индивидуальные котировки. Аккаунты, синхронизация между устройствами, история курсов и уведомления в текущую версию не входят.

## Технологический стек

- Next.js 16 App Router, React 19 и TypeScript.
- Serwist (`@serwist/next`) для service worker и precache.
- IndexedDB через `idb` для локального снимка курсов и настроек.
- `big.js` для десятичной арифметики без ошибок двоичной плавающей точки.
- dnd-kit для touch- и keyboard-доступной сортировки валют.
- Radix UI, Tailwind CSS и собственный Material 3-inspired визуальный слой.
- Node.js 24.x LTS, npm и Vercel-совместимая production-сборка. Major-версия совпадает с настройкой Vercel; Node.js 26 не используется до появления LTS-статуса и поддержки платформой.

## Архитектура

Пользовательский интерфейс реализован в `components/converter-app.tsx`. Серверный адаптер `app/api/rates/route.ts` скрывает различия публичных ответов Coinbase и отдаёт клиенту единый контракт. Расчёты, валидация, ввод, локализация и хранилище вынесены в независимые модули каталога `lib`.

API приложения:

```text
GET /api/rates
GET /api/rates?force=1&at=<timestamp>
```

Обычный запрос использует шестичасовой серверный кеш. Вариант `force=1` применяется только для ручного обновления и обходит кеш. В offline-режиме и при `navigator.onLine === false` клиент не выполняет ни один из этих запросов.

Нормализованный ответ:

```ts
type RateSnapshot = {
  base: "USD";
  updatedAt: string; // ISO 8601
  currencies: Array<{ code: string; name: string; type: "fiat" | "crypto" }>;
  rates: Record<string, string>; // положительные decimal-строки
};
```

Перед сохранением ответ валидируется функцией `isSnapshot`. Последний корректный снимок записывается в IndexedDB только целиком, поэтому невалидный или оборванный ответ не заменяет рабочие данные.

## Источники данных

Используются публичные endpoint'ы Coinbase API без API-ключа:

- `https://api.coinbase.com/v2/exchange-rates?currency=USD` — актуальные коэффициенты относительно USD;
- `https://api.coinbase.com/v2/currencies` — каталог фиатных валют;
- `https://api.coinbase.com/v2/currencies/crypto` — каталог криптовалют.

Документация провайдера:

- [Coinbase Exchange Rates](https://docs.cdp.coinbase.com/coinbase-business/track-apis/exchange-rates)
- [Coinbase Currencies](https://docs.cdp.coinbase.com/coinbase-app/track-apis/currencies)

Доступность, состав каталога и значения курсов зависят от Coinbase. Если провайдер временно недоступен, приложение продолжает использовать последний валидный локальный снимок.

## Формула и форматирование

Все курсы нормализованы к USD. Произвольная пара вычисляется по формуле:

```text
result = amount × rates[to] ÷ rates[from]
```

Арифметика выполняется `big.js`. Отображение локализуется через `Intl.NumberFormat`: `en-US` для английского и `ru-RU` для русского. Пользователь выбирает максимальное число знаков после десятичного разделителя от 0 до 10; значение по умолчанию — 2. Настройка влияет только на отображение, а не на точность внутреннего расчёта.

## Кеширование и offline-first поведение

- Ответ `/api/rates` кешируется на Vercel CDN на 21 600 секунд (6 часов).
- При запуске сохранённые настройки и снимок курсов читаются из IndexedDB до сетевого запроса.
- Автоматическое обновление выполняется только при отсутствии снимка или возрасте не менее 6 часов.
- Ручная кнопка всегда запрашивает свежий снимок, если сеть разрешена.
- Ручной offline-режим и отсутствие соединения блокируют запросы курсов.
- При первом offline-запуске без снимка показывается объяснение о необходимости одного подключения.
- Service worker использует NetworkOnly для `/api/rates`, чтобы не подменять логику актуальности собственным HTTP-кешем.

## Локальные данные

В IndexedDB `currenzy`, object store `app`, сохраняются:

- активная валюта и сумма;
- выбранные валюты и их порядок;
- язык, тема, offline-режим и точность результата;
- последний валидный `RateSnapshot`.

Серверная база данных, cookies, аналитика и пользовательская идентификация не применяются. При добавлении новых настроек `normalizePreferences` объединяет старые данные с актуальными значениями по умолчанию.

## PWA и иконки

Manifest доступен по `/manifest.webmanifest`, `display` установлен в `standalone`, стартовый URL — `/`. Для установки объявлены:

- `/icon-192.png`, 192×192;
- `/icon-512.png`, 512×512, purpose `any`;
- `/icon-maskable-512.png`, 512×512, purpose `maskable`, с безопасным внутренним полем;
- `/apple-touch-icon.png`, 180×180, через Next.js metadata для iOS.

Service worker генерируется в `public/sw.js`. Оболочка приложения, шрифты и локальные изображения включаются в precache. В production установка требует HTTPS; localhost является разрешённым браузерами исключением.

## Доступность и адаптивность

Интерфейс поддерживает системную светлую/тёмную тему, `prefers-reduced-motion`, крупные touch-targets, физическую клавиатуру и keyboard-сортировку. На телефоне используется один столбец; с ширины 900 px — двухколоночная компоновка, использующая доступную площадь без горизонтального скролла.

## Разработка и проверки

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run lint
npm run build
```

Тесты покрывают арифметику, локализованное форматирование и точность, редактирование ввода, шестичасовое окно актуальности, offline-защиту, нормализацию ответов, миграцию настроек и полноту переводов.

## Развёртывание

Репозиторий рассчитан на прямой импорт в Vercel. Секреты и переменные окружения не требуются. Команда сборки — `npm run build`; Next.js автоматически предоставляет UI, manifest и `/api/rates`. После развёртывания следует проверить установку PWA в Chromium DevTools и повторный запуск с отключённой сетью.
